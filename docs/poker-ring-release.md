**マージと公開のボタンはオーナーが押す。** 秘密の値（キー・パスワード）はオーナーが各サービスの画面で入れる。

## 1. ゲームサーバー（Railway）— オーナー作業

1. Railwayのプロジェクトで、テスト用の `poker-room-server` を複製して本番用の環境（例：production）を作る。デプロイ元のブランチは `main`。
2. 本番用の変数を入れる（値は Supabase 本番プロジェクトの画面からコピー）。

| 変数 | 値 |
|---|---|
| `POKER_SUPABASE_URL` | `https://tjmeqnzvuoguoffltxrp.supabase.co` |
| `POKER_SUPABASE_SECRET_KEY` | 本番の secret（service role）キー |
| `POKER_SUPABASE_PUBLIC_KEY` | 本番の publishable（anon）キー |
| `POKER_ROOM_KEYS_JSON` | `{"prod-v1":"<新しい鍵>"}`。鍵はテスト用と別に新しく作る（ターミナルで `openssl rand -base64 32`）。一度決めたら作り直さない |
| `POKER_ROOM_ACTIVE_KEY` | `prod-v1` |
| `POKER_ROOM_ORIGINS` | `["https://pokersummit.jp","https://www.pokersummit.jp"]` |
| `POKER_ROOM_HOST` / `PORT` | `0.0.0.0` / `3001` |
| `POKER_ROOM_MAX_ROOMS` | `16` |

3. デプロイ後、`https://<本番サーバーのURL>/readyz` が `{"ok":true}` を返すことを確認。
   - CPU卓（自動対戦）は本番では動かない作りになっている（本番DBを見たら止まる）。

## 2. サイト（Vercel）— オーナー作業

Production の環境変数に追加：

| 変数 | 値 |
|---|---|
| `POKER_ROOM_SERVICE_ORIGIN` | `https://<本番サーバーのURL>` |

| `NEXT_PUBLIC_POKER_TOURNAMENTS` | `off`（大会を全部隠す。大会を出す時に消す） |

## 3. 本番DBの移行 — Claudeが実行（オーナーの「やって」の後）

- 中身：`scripts/poker-release/production-upgrade.sql`（ゲーム用の33個の変更を1つのトランザクションにまとめたもの。途中で失敗したら全部取り消し。2回流しても壊れない）。
- 本番にすでにある卓設定・大会設定・ニュースはそのまま。CPU卓の表はテスト環境専用なので入れない。
- 実行後に確認：リング用の関数がそろっていること、既存の大会・ニュースが変わっていないこと。

## 4. 公開

1. PR #485 をオーナーがマージ → Vercel と Railway が本番に反映。
2. 管理画面「リングゲーム卓設定」で次の5卓を作る（最初は非公開）。どれも6人卓・24時間オープン。持込は最低40BB・最大100BB（オーナー指示 10/27「テーブルによってMAXバイイン決めて」）。

   | 卓名 | SB/BB | 最低持込 | 最大持込 |
   |---|---|---|---|
   | SUMMIT 1/2 #1 | 1/2 | 80 | 200 |
   | SUMMIT 1/2 #2 | 1/2 | 80 | 200 |
   | SUMMIT 1/2 #3 | 1/2 | 80 | 200 |
   | SUMMIT 2/5 | 2/5 | 200 | 500 |
   | SUMMIT 5/10 | 5/10 | 400 | 1,000 |

   運営アカウントで着席→数ハンド→退出を確認。
3. 卓を「公開」にする＝会員が遊べる状態（全会員に公開）。

## 5. 決めておくこと

- 決定済み（10/27）：チップは完全無料。最初に 3,000。0になったら卓の上の「補充して座り直す」で 3,000 に戻して同じ席へ（ロビーの残高からも補充できる）。全会員に公開。卓は上の5つを24時間。
- 規約に「チップはサイト内専用で、購入・換金・譲渡はできません」を追加。

## 6. 戻し方

- すぐ止める：管理画面で卓を全部「非公開」に（遊んでいる人のチップはハンド終了後に返る）。
- 表示ごと隠す：Vercel の `POKER_ROOM_SERVICE_ORIGIN` を外す（ロビーはサンプル卓だけになる）。
- コードを戻す：main のマージを取り消すPR。DBの追加分はそのまま残しても他の機能に影響しない。
