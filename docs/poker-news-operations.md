# ポーカーニュース運用

- 一覧 `/poker-news`、運営管理 `/admin/poker-news`。
- TOPは4件を表示。「更に表示する」で最新10件まで表示し、「全て見る」で一覧へ進む。
- 一覧は公開ニュースを日付・作成日時・IDの降順で並べ、1ページ10件。日付（掲載日・収集日）・カテゴリ・見出し／概要のフリーワードで検索できる。
- 関連記事は `blog_entries` の記事を選択。公開中の関連記事だけにリンクする。
- 新規ニュースは公開チェックをOFFにすると下書き。ONでTOPと一覧に反映。削除の代わりにOFFで非公開に戻せる。

## ChatGPTから登録

接続済みSupabaseの権限が利用できるセッションでは、依頼に応じて `public.poker_news` へ登録・更新できる。今回の21件も接続済み機能から登録済み。独立した公開APIやOpenAI APIキーは不要。自動巡回・定期収集を設定したものではない。

接続が使えない場合は、下記形式のJSON配列を作成し、管理画面の「ChatGPTのニュースデータを一括取り込み」に貼り付ける。最大100件。同じ `import_key` は更新されるため、既存データのキーを維持する。省略時は参照URLと見出しから安定したキーを作る。`active` は省略するとfalse（下書き）。

```json
[{
  "import_key": "news-20261024-01",
  "title": "ニュースの見出し",
  "summary": "ニュースの概要",
  "category": "国内大会",
  "news_date": "2026-10-24",
  "source_url": "https://example.com/news",
  "source_label": "公式情報を見る",
  "related_blog_id": null,
  "active": false
}]
```

カテゴリ：国内大会／海外大会／大会結果／業界情報／配信・アプリ／未確認・参考。
関連記事を指定する場合は、実在するブログのUUIDを使う。タイトルや外部URLはこの欄に入れない。
直接DB登録でも `lib/poker-news-input.ts` と同じ検証を行い、`updated_at` を更新する。通常の保存は `/` と `/poker-news` と公開データキャッシュを無効化する。接続済みDB操作からの変更はTOPの60秒キャッシュ後に反映し、一覧は次回アクセスで反映する。

## 初期データ

`scripts/data/poker-news-20261023.json` は提供された10/23シートのニュース16件・未確認参考5件の21件。記事案4行はニュースではないため含めない。ニュースの日付は収集対象日の10/23で、各発表日時が同日であることを示さない。参考情報は公開画面でもその区分と注意書きを表示する。既存のニュース自動下書き作成 `news_auto_items` は別用途であり変更しない。
