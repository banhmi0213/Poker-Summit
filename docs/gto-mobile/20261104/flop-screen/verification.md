# フロップ戦略のPC 1画面表示

オーナー11/4の例外指示。ステージングのみ。main/staffへの取り込みはリング担当。

実FlopStrategyPanel・PokerAccountWorkspace・公開フロップJSONを使ったChromiumのローカル検証。NextのLink、アバター取得、記録同期はハーネスで置換。ログインした実サイトや実iPhoneの確認とは区別する。

- 1366×768、1440×900、1920×1080：documentのscrollWidth/Heightがviewport以内。13×13表は正方形、文字14px。A6s選択時の割合・EV、後を見るボタンを含めて表示。
- 各サイズで後を見るを3回進めても縦横のスクロールなし。最初から戻り、説明を展開してもページのスクロールなし。
- 375×812と1099×900：変更前後のスクリーンショットが全ピクセル一致。
- フロップ選択・ターン探索・GTO対戦・連打の既存テスト11件成功。esbuildによる実コンポーネントのバンドル成功。
- CSSの追加はすべてmin-width:1100pxの中。配色、戦略計算、ボタン文言を維持。

高さは実際の表領域上端を測り、画面下端までの残りと列幅の小さい方を表の一辺に採用。全体のscaleやoverflow:hiddenで内容を切り捨てない。長文はPCだけ「この画面について」にまとめ、スマホの既存説明を維持。
