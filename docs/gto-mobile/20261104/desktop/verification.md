# PC専用：GTO全画面の横幅と文字

比較元ステージング：b140a49e134d067abe7fda98cd718c20e27ad49f。

本体はCSS5ファイルへの @media (min-width:1100px) の追記だけ。既存CSSはバイト単位で保持。TS/TSX、部品の中身、採点・保存・表データ・配色・ボタン文言は変更なし。account側はGTOと対戦・プリフロップ表・フロップ戦略・レンジ練習・弱点分析のaria-labelで限定し、プロフィールなどには適用しない。

PCは高さ合わせによる縮小を解除。幅最大1800px・左右28px、ナビを上部へ配置。表は左400px＋残り幅、文字16px・マス38px。フロップ選択は13ランク1行・スート4個1行、約254pxに圧縮。説明と操作の続きは表の下へ。対戦は大きな卓＋操作/記録の2列。本文15px以上、見出し18px以上、凡例14px以上。「最後まで見る」は20pxのチェックボックス・横並びラベル。新規ブラウザ状態でオフを確認。保存値の読み書きは変更していない。設定・開始ボタン・説明の横はみ出しなし。

実コンポーネントPokerAccountWorkspaceを含むChromium確認：フロップ、プリフロップ、1ハンド対戦、連打、レンジ練習、弱点分析について1280/1600/1920pxの画像。対戦は実workerで開始後の卓も撮影。公開表JSONは実ファイル、弱点API/記録同期は分離fixtureを使用。

375/768pxは各6画面、同じコンポーネント状態で変更前CSSから変更後CSSへ切り替えてフルページ比較。寸法と表示が一致。PNGの画素差は最大1/255（背景グラデーションの描画揺れ）以下。比較画像は左が変更前、右が変更後。動作を変えるJS変更なし。結果はverification.json。PCは自然な高さでスクロールできるようにし、文字を縮小して1画面に押し込めない。
