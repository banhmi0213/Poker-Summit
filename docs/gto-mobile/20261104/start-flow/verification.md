# スマホGTOの開始・プレイ分離

375px・320pxの実コンポーネントと実GTO workerをChromiumで操作。実iPhoneの検証とは区別する。

- 開始前に選ぶ欄と開始ボタンを表示。設定トリガーを廃止し、プレイ中の設定・タブ・記録欄を隠す。「やめる」で開始前に戻る。
- 連打は一度だけ自動送りをオフへ移行。その後の選択は端末へ保存。手動採点を3.2秒待って保持を確認。
- 自動送りは2.5秒以上、触れた後3.1秒停止、ミス時も3.1秒以上保持。復習件数バッジと設定のreload保存を確認。
