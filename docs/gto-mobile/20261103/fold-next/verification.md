# フォールド後の次ハンド

375pxの実Chromium、実GtoTrainer・実GTO worker・実ハンドエンジンで検証。会員保存APIだけは固定の失敗応答を使用。

- 初期値は最後まで見るオフ。フォールド後は棒グラフと次へを表示。
- 相手の進行が止まり、相手のカードと当該ハンドの結果BBを表示しない。
- 次へまで待ってもアクションログは変わらず、成績は1ハンド・採点1回。
- 次へで配り直しても前のハンドを重複計上しない。
- 下から出る対戦の設定で最後まで見るをオンにすると、フォールド後も相手を決着まで進める。
- 最後まで進めてもハンド数を重複計上せず、再読み込み後もスイッチを保持。
- ハンドエンジン7テスト成功。席を変えた32ケースで、フォールド時点の損失と決着後の損失が同じで、払い戻し込みの全チップ総数が一致。

添付はローカルの実コンポーネントによる375px検証画像。iPhone実機の画像ではない。
