# プレイ中の更新抑止

375px / 320px / PC1280pxの実Chromiumで検証。
対戦・連打・クイズのプレイ中だけスマホのhtml/bodyにoverscroll-behavior:noneを適用。
連打から対戦へのタブ変更、表への移動、PC幅への変更で元の値へ戻ることを確認。
スマホ幅に戻した場合はプレイ中のみ再適用。PCでは適用しない。
全画面の内側スクロール領域にも同じ指定を適用し、設定シート内の通常スクロールは維持。

添付は固定データと実コンポーネントによる通常タブの画像。実iPhoneの指によるバウンス動作の確認ではなく、ブラウザのCSS実効値と後始末を検証したもの。
