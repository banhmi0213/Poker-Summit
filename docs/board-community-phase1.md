# サミット掲示板：交流機能 第1段階

## 操作

- 本文で `@` と会員名を入力し、候補を選ぶと個人メンションになる。表示は青色。対象は会員IDで保存し、同名の候補はID末尾で区別する。DB側で実在するプロフィール名に正規化し、偽の表示名を防ぐ。1投稿10件まで。全員通知はない。
- コメントに「返信する」を設置。返信は元コメントの下で折りたたみ、閉じていても返信件数を表示する。返信への返信も同じ元コメントの会話にまとめる。元コメントは100件/ページ、会話内の返信は20件ずつ追加取得する。
- リアクションは「参考になった・ありがとう・ナイスプレイ・考えたい」の4種類。各種類で1会員1件、再押下で解除。件数は保存済みデータの集計。
- フォローと通知は独立した設定。フォローを解除しても通知設定や投稿は残る。フォロー中一覧はマイページから確認できる。
- 通知ONではメンション、自分のスレッドへのコメント、自分のコメントへの返信を通知する。フォロー中なら他の新着コメントも通知する。OFFはそのスレッドからの新着通知をすべて止める（既に届いた通知は残る）。自分の投稿は自分に通知しない。同じ投稿から同一会員への通知は1件（メンション優先）。メール・プッシュ通知ではない。
- マイページの「サミット通知」に既読操作と投稿への導線を設置。返信通知は `?focus=<replyId>` で該当ページ・会話を開く。
- スレ主のみ回答済みに変更できる。特定のコメントを選択することも可能。変更は一度解除してから選び直す。返信は引き続き可能。
- 掲示板一覧・スレッド詳細に折りたたみの使い方を追加。既存の会員限定閲覧、通報、投稿者バッジ、画像添付を維持する。

## データと権限

`board_replies.parent_reply_id` と `board_thread_preferences` / `board_reactions` / `board_resolutions` / `board_notifications` を追加する。既存投稿の書き換え・削除は行わない。

各テーブルはRLS有効。フォロー・通知設定・通知既読は本人のみ。回答済みはDBでもスレ主のみ。別スレッドへの返信、孫返信の直接作成、投稿後の返信先変更、他人のリアクション削除を防止する。停止会員は新機能を操作できない。

通知配送だけは他会員の通知を作成する必要があるため、非公開 `private` スキーマのトリガー関数で実行する。認証済み投稿者との一致を確認し、直接実行は許可しない。新機能のRPCはSECURITY INVOKERで、匿名には実行権限を付与しない。非表示のスレッド・返信は関連機能でも読み取らせない。

## 2アカウントでの確認手順

1. Aでスレッドを作成。Bでフォローし、通知ONを確認する。
2. Bの本文でAを候補からメンションし、コメントを投稿。Aのマイページで通知が1件届くことを確認する。
3. AがBのコメントの「返信する」から返信。Bで「返信1件を表示」→「返信を閉じる」を操作する。
4. A/Bで同じリアクションを押し、人数が2になること、取り消すと1に戻ることを確認する。
5. Bで通知OFF。Aから新しい返信・メンションを投稿し、Bに新着通知が増えないことを確認する。
6. Bのマイページでフォロー中一覧、解除、通知の既読を確認する。
7. Aのみ回答済みにできること、Bには操作ボタンがないこと、一覧のマークを確認する。
8. スマートフォンで使い方の展開・折りたたみ、通知リンクから対象返信が開くことを確認する。
