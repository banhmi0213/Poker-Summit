# 記事データの取り込み（API不要）

1. ChatGPTに「Poker Summitの記事取り込み用JSON、version: 1の形式で作成」と依頼する。
2. `/admin/blog` の新規記事欄にある「記事データを取り込む」へデータを貼り付ける。JSONファイルからの読み込みも可能。
3. 「取り込み内容を確認」でタイトル・本文構成・SEO・照合結果を確認する。
4. 「新規記事の編集欄に反映」で編集欄へ入力する。入力中の記事・選択した画像は置き換わる。登録済み記事は上書きしない。
5. 画像があれば手動登録する。画像なしでも下書き保存でき、本文の写真枠・ALT・説明も保持される。公開時はアイキャッチと本文の写真を登録するか、不要な本文写真枠を削除する。
6. 「保存前にプレビュー」で確認して「下書き保存」。公開は別途、内容を確認して「公開して保存」で行う。

APIキー・AI用環境変数・追加DBマイグレーションは不要。
取り込み・検証はブラウザ内で行い、生成APIや外部画像URLへアクセスしない。
保存は既存の管理者権限確認と画像検証を持つ保存処理を使う。
保存後に再取り込みする場合は新規記事画面を開く。保存中の取り込みは無効化する。

## データ形式

`version`, `title`, `slug`, `category`, `body` が必須。他の項目は省略可能。
次は最低限のサンプル。画面の「入力例を表示」には画像・リスト・表を含む例がある。

```json
{
  "version": 1,
  "title": "ポーカー店への初来店で確認したいこと",
  "slug": "first-poker-room-checklist",
  "category": "初心者ガイド",
  "summary": "来店前に料金や初心者講習を確認しましょう。",
  "seoTitle": "初めてのポーカー店｜来店前の確認事項",
  "metaDescription": "初来店の前に、料金、初心者講習、滞在時間について確認しておきたいことを紹介します。",
  "imageAlt": "ポーカーテーブルとチップのイラスト",
  "body": [
    { "type": "paragraph", "text": "初来店では、分からないことをスタッフに相談してみましょう。" },
    { "type": "heading", "text": "参加にかかる料金を確認する" },
    { "type": "paragraph", "text": "店舗によって料金体系が異なります。参加費のほかに必要な費用があるか確認してください。" }
  ],
  "relatedArticles": [],
  "references": [],
  "showToc": true,
  "showBreadcrumbs": true
}
```

| 項目 | 仕様 |
| --- | --- |
| `version` | 数値 `1` |
| `title`, `slug`, `category` | タイトル160文字、スラッグ120文字以内。カテゴリは既存カテゴリ名 |
| `summary`, `seoTitle`, `metaDescription` | 600 / 160 / 300文字以内 |
| `authorName`, `authorProfile` | 任意。実際の著者情報のみ。120 / 1000文字以内 |
| `imageAlt`, `imageRights` | アイキャッチALT案300文字、確認済み権利情報1000文字以内 |
| `body` | 1〜100ブロック。`paragraph`, `heading` (H2), `heading3` (H3), `list`, `table`, `image` |
| `list` | `items` に文字列配列、`ordered` は任意の真偽値 |
| `table` | `rows` に文字列の二次元配列。列数はそろえる |
| `image` | `alt`, `caption` のみ。画像ファイルは画面で登録 |
| `relatedArticles` | 公開記事のスラッグ・ID・完全一致タイトルの配列（最大12件）。未一致・同名複数は警告してスキップ |
| `references` | `label`, 任意の `url` を持つ配列（最大30件）。http(s)のみ |
| `showToc`, `showBreadcrumbs`, `searchIndex`, `includeInSitemap` | 真偽値。省略時true |

全体15万文字以内。JSONコードフェンス付きでも読み込める。
既存スラッグとの衝突はエラー。同じタイトルは許容する。
記事ID・公開状態・公開日・ピックアップ・画像URL・保存済み画像パス・canonicalは取り込まない。
取り込んだデータは新規・下書き・サイト内記事として初期化する。
不正なJSONや形式エラーでは編集欄を変更しない。画像・出典・ALTは公開前に確認する。

`node --test tests/blog-import.test.cjs`

UI確認：新規画面→入力例→確認→反映→本文・SEO・表・画像ALT→画像登録→プレビュー→下書き保存。
